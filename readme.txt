[center][size=16pt][b]Global New Topic 1.0.0[/b][/size][/center]

[b]Description[/b]
Adds a collapsible "Start a new topic" composer to normal SMF 2.1 forum pages.

The user can select the destination board from a dropdown. Only boards in which the current user has SMF's [tt]post_new[/tt] permission are listed.

[b]Features[/b]
[list]
[li]Global new-topic composer on normal forum pages[/li]
[li]Collapsible/expandable interface[/li]
[li]Board dropdown grouped by category[/li]
[li]Uses SMF's native post form structure, rich-text/BBC editor controls and native CSS classes[/li]
[li]Uses SMF native posting controls and submits through SMF's native [tt]post2[/tt] action[/li]
[li]Per-member-group access in the Admin Center[/li]
[li]Normal SMF board posting permissions are always respected[/li]
[li]English, German formal and German informal language files[/li]
[/list]

[b]Installation[/b]
Upload the ZIP through SMF Admin Center -> Package Manager and install it.

After installation open:
Admin Center -> Configuration -> Global New Topic

Enable the feature and select all member groups that may use it.

[b]Uninstallation[/b]
Uninstall the package through SMF's Package Manager. The package removes its hooks, files and settings.

[b]Compatibility[/b]
SMF 2.1.x
